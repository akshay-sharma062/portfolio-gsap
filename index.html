Multi-Client Daily Ad Reporting System

Built for 13 client accounts running independently with complete client-wise data isolation and eliminating repetitive manual ad-reporting work.

  • Fetches daily Meta Ads data — spend and cost per landing page view — per client.
  • Integrates client-specific Flexi lead data and calculates daily leads & CPL.
  • Generates daily reports: spend, leads, CPL, 7-day average CPL, cost per landing page view, balance left.
  • Consolidates every client report into a single Master Daily Report while keeping data isolated.
  • Checks Client ID + Date before writing, preventing duplicate entries and cross-client mixing.
  • Sends each client's report to the correct mapped recipient(s) automatically via Pabbly Connect.
